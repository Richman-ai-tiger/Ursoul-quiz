# 测测你的灵魂对应哪位中国历史人物

一个纯前端的趣味人格测试：40 道生活化单选题，匹配 7 位中国历史人物。
单文件 HTML，无后端、无依赖，双击即可运行。

## 在线地址
部署在 GitHub Pages 后，访问：`https://<你的用户名>.github.io/<仓库名>/`

## 本地运行
直接双击 `index.html`，或用任意浏览器打开。

## 结构
- `index.html` —— 页面 + 样式 + 逻辑全部在这一个文件里
- 题库：`QUESTIONS`（40 题）
- 人物：`ARCHETYPES`（7 位：诸葛亮 / 李世民 / 苏轼 / 荆轲 / 李白 / 霍去病 / 陶渊明）
- 评分：`scoreAnswers()`（智·势·情·义·逸 五维 → 七人格匹配）

## 说明
趣味内容，不构成任何心理评估或诊断。
